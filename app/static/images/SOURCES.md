# NCSC interface assets

- `ncsc-seal.jpg`: logo supplied by the repository owner for this interface.
- `ncsc-summit.webp`: locally optimized version of a National Senior Citizens Summit photograph displayed on the [official NCSC homepage](https://www.ncsc.gov.ph/). [Original photograph](https://static.wixstatic.com/media/dccc60_b949c6ccd9e34628b7370ad13c2a64c4~mv2.jpg).

The photograph and logo are bundled locally so using the app does not contact image hosts. The interface uses system fonts and locally served SVG icons.

Employee exports, reports, databases, and account credentials are excluded from this public repository. The workbook in `tests/fixtures/` is a synthetic test fixture containing fictional DEMO identifiers.
